# 配置目录

> 本文件由 `node scripts/generate-docs.mjs` 生成；请勿手工编辑。

`config.json` 的全部字段，来自 `@xm/contracts` 的 `Config` schema。

层级：内置默认 < `${paths.config}/config.json` < 传入 cwd 的 `.xiaoming/config.json`。**配置层刻意不接环境变量**——接上就等于给了一条"把密钥塞进 env"的合法路径，而 `shell.exec` 会把整个环境原样交给子进程（docs/06）。

共 14 个字段。

| 字段 | 类型 | 可选 | 默认值 |
|---|---|---|---|
| `model` | 对象 | 否 | — |
| `model.main` | string | 否 | — |
| `model.subagent` | string | 是 | — |
| `model.summarize` | string | 是 | — |
| `providers` | 映射 | 否 | `{}` |
| `prices` | 映射 | 否 | `{}` |
| `permission` | 对象 | 否 | — |
| `permission.rules` | 数组 | 否 | `[]` |
| `tools` | 对象 | 否 | — |
| `tools.disabled` | 数组 | 否 | `[]` |
| `tools.presentation` | 枚举（native、code、both） | 否 | `"native"` |
| `workspace` | 对象 | 否 | `{"mode":"choose"}` |
| `workspace.mode` | 枚举（choose、fixed、home） | 否 | `"choose"` |
| `workspace.defaultPath` | string | 是 | — |
