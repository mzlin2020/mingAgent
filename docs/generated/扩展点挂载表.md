# 扩展点挂载表

> 本文件由 `node scripts/generate-docs.mjs` 生成；请勿手工编辑。

`test` profile 真装配一次之后，每个扩展点上挂着哪些插件行、按什么顺序派发。

顺序**就是**派发顺序：waterfall 上排在前面的先拿到 `next`，所以这张表是"一次调用经过了什么"（ADR-0055）唯一可靠的答案。

注意四个内建 profile 的业务行相同，只有 surface 与 clock/ids 提供者不同，因此这张表对 desktop / headless / cli 同样成立。
