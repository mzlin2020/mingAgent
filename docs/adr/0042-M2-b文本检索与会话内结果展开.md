# ADR-0042 · M2-b 文本检索与会话内结果展开

- **状态**：🟢 Accepted
- **日期**：2026-08-12
- **Superseded by**：[ADR-0051](./0051-索引查询时机与无ripgrep降级.md)（仅第 1 节"ripgrep 是硬依赖"那部分；`search.text` 的工具契约、截断标记与 `result.expand` 仍然有效）
- **相关**：[ADR-0009](./0009-工具Schema子集与结果截断.md)、[ADR-0013](./0013-存储引擎选型与EventStore端口.md)、[ADR-0024](./0024-路径能力网关.md)、[M2 阶段划分](../M2-阶段划分.md)

## 背景

M2-b 要交付两件互相依赖的能力：用 ripgrep 检索工作区文本，以及在统一结果截断把全文写入 BlobStore 后，按范围继续读取被省略的内容。

现有运行时已经在 `tool.end.fullRef` 持久化截断全文的 `BlobRef`，但对模型可见的标记只展示 12 位短 hash，无法作为机器可用的展开参数。BlobStore 又是跨会话共享的全局内容寻址存储；若 `result.expand` 接受任意完整 hash 并直接读取，会成为绕过会话边界和文件策略的内部数据旁路。

搜索也不能退化成 `shell.exec ["rg", ...]` 的提示词约定。那样既没有稳定输出契约，也无法可靠表达全局结果上限、二进制/忽略规则和 ripgrep 缺失。

## 决策

### 1. 文本检索是独立内建工具

工具名为 `search.text`，实现在 `@xm/tools-core`，直接以 `spawn("rg", argv, { shell: false })` 启动 ripgrep，并消费 `--json` 输出。

- 入参只保留 `pattern`、`path`、`glob`、`caseSensitive`、`context`、`maxResults`。
- `path` 进入现有路径能力网关；工具声明 `fs.read`，继续经过策略、并发资源声明与统一结果截断。
- 匹配位置统一输出为 1 起算的 `path:line:column`；上下文行用 column `0`，不伪装成匹配。
- 默认遵守 ripgrep 的 ignore 规则并跳过二进制文件，结果中必须明说；达到全局上限时也必须明说。
- ripgrep 不可执行、退出失败或调用被中断都返回不同的明确结果，不把它们伪装成“无匹配”。

不内建正则引擎，不引入常驻进程、tree-sitter、FTS5 或索引。

### 2. 截断标记携带完整但不授予权限的定位符

截断标记改为输出 `blob:sha256:<64 位 hash>`。这是机器可复制的定位符，不是读取授权；面向 UI 的 `formatBlobRef()` 仍保持短格式。

`tool.end.forModel` 继续保存当时实际喂给模型的截断文本，`tool.end.fullRef` 继续保存未截断全文引用，不新增事件类型，也不改变回放语义。

### 3. `result.expand` 只展开当前会话可达的工具结果

工具名定为 `result.expand`，实现在 `@xm/runtime`。它通过两个窄依赖工作：BlobStore 读取端口，以及“给定 sessionId + hash，解析当前会话 `tool.end.fullRef`”的回调。

- 只有 hash 出现在当前会话已持久化的 `tool.end.fullRef` 中才允许读取。
- 不接受任意文件路径，不向工具暴露 EventStore 或通用 SessionRuntime。
- 按 1 起算的 `offset` + `limit` 读取行范围；流式扫描 blob，不把全文一次物化进内存。
- 引用不存在、属于别的会话或 blob 已损坏时显式失败。
- 工具声明空能力集并进入空能力 allowlist：它只能重读当前会话已经产生、且模型已看到截断标记的结果，没有会话外副作用，也不是通用 BlobStore 浏览器。

## 后果

- 正面：搜索、路径判定、策略、截断、blob 落盘和范围展开形成一条可回放纵切。
- 正面：完整 hash 可供模型调用，但跨会话 hash 仍无法读取。
- 正面：搜索输出由 ripgrep JSON 归一化，不依赖人类终端格式或平台颜色配置。
- 代价：生产装配必须提供会话内 fullRef 解析回调；遗漏会在编译期暴露。
- 代价：首版依赖主机可执行的 ripgrep。缺失时工具保留可见并报告安装/平台问题，不静默降级成另一套搜索实现。
- 重新评估条件：若以后需要展开非工具结果 blob，必须为新的来源定义独立的会话可达性规则，不能放宽成任意 hash 读取。
