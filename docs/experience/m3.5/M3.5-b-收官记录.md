## 二、验收

- 单测覆盖三步让位与夹紧、非法视口、用户关栏、自动关闭不碰偏好。
- `store` 的 `openIds` / `goHome` / `closeTab` 本段未改，ADR-0037 的会话切换行为保持。
- 真机「拖窄 → 拉宽 → 按原宽度回来」与 a 段截图同一笔欠账：当前环境没有桌面会话。
  投影函数已经用字面量视口钉死（800 关、1200 回 360/400）。

## 三、反向演练，逐条看它红过一次

| # | 构造 | 实际报错 |
|---|---|---|
| 1 | 去掉 `CENTER_MIN` 下限（`vp >= pref` 就算放得下） | `expected { center: 579, details: 360 } to deeply equal { center: 939, details: +0 }` |
| 2 | 自动关闭时回写 `pref.width = 0` | `Cannot assign to read only property 'width'`（用例把偏好 `Object.freeze` 住了）；还原后「拉宽按原宽度回来」绿 |

第 1 条的输入是字面量 `939` / `360`，不是 `CENTER_MIN + DETAILS_MIN - 1`——
用常量拼输入会跟着被拿掉的下限一起漂，演练就假绿。
