## 四、全程不变

1. 状态 = `reduce(events)`。`localStorage` 只放 UI 偏好（主题 / Enter / 详情栏宽）。
2. 渲染层零 Node：三个开关不动，preload 无通用入口。
3. 契约两侧校验。占用与卡片都是 sidecar，不进事件闭集。
4. 渲染层不认识任何具体工具。
5. 权限只有 allow / deny，设置页不能加 `allow`。
6. 不新建包，`.dependency-cruiser.cjs` 未改规则。
7. `ALLOWLIST` 未增行。
