## 一、交付了什么

| 层 | 落点 |
|---|---|
| 宽度轴 | `lib/layout.ts` 三个数字 + `.chat-axis` 上的 `--xm-chat-content-width` / `--xm-composer-card-max-width` / `--xm-chat-gutter`。Home / 设置 / 对话共用，替掉 `COLUMN` |

| 回到底部 | 零高度槽 + 34px 圆钮，`margin-top: -34px` |

## 二、验收

- ADR-0058 四种卡片渲染器用例全绿（`card-registry.test.ts`）；工具行源码闸门拦住内建工具名。
- `prefers-reduced-motion` 下 shimmer 与扫光带 `animation: none`（CSS 用例钉死选择器）。
- 贴底：`isPinnedToBottom`；手动上滚后 `pinned` 变 false，槽里的圆钮出现。
- 📌 **待补**：同一段真实会话（10+ 次工具调用）改前改后截屏，以及「一屏可见工具调用数」。
  与 a/b 段同一笔欠账——当前环境没有桌面会话，`electron` 起不来。
  结构上收起态是 24px 行，旧块状卡片光标题条就接近这个高度。

## 三、反向演练，逐条看它红过一次

| # | 构造 | 实际报错 |
|---|---|---|
| 1 | 把 `TO_BOTTOM_LAYOUT.buttonMarginTop` 改成 `0` | `expected { buttonMarginTop: 0, … } to deeply equal { buttonMarginTop: -34, … }` |
| 2 | 渐变遮罩改用百分比 | 机械化一半：`layout.test.ts` 要求 `transparent 0px, var(--color-canvas) 36px`，写成 `36%` 会红。真机长高输入框把正文糊掉的截图对照仍待 GUI |

第 1 条实测日期 2026-08-16：改完跑 `scroll-pin.test.ts` 的「不撑高」用例，红在字面量 `-34`，不是用常量拼出来的期望——拿掉负 margin 不会让期望跟着漂。
