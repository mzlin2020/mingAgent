- **执行日期**：2026-08-13

- **阶段协议**：每个子阶段聚焦测试通过后才进入下一阶段；全部完成后重新执行一次总验收。

## 自动化纵切

1. todo 清单持久化、重启回放和桌面投影。
2. ripgrep 搜索、截断 Blob 与会话内范围展开。
3. checkpoint v2 覆盖文件、目录、大文件、多目标和整组恢复。
4. 精确预览/应用、多文件漂移零写入和失败回滚。
5. diff 逐块选择、拒绝全部零写入、IPC 和大 diff 挂载上限。
6. 临时 Git 仓库的 status/diff/branch/path-only commit，以及冲突、hook、取消和既有暂存保护。
7. 冷索引 fallback、真实 tree-sitter WASM AST、FTS5、增量删除/重命名/ignore 与损坏重建。
8. 75% 上下文预算、一次持久摘要、最近四轮原文、重开复用与稳定前缀。
9. 隔离子 Agent 的独立 session/seq、只读工具白名单、取消/超时/失败/重启收尾和污点回传。

## 总闸门

- `pnpm verify`：工具链、workflow、四套 TypeScript 检查、ESLint、全部 Vitest、内核覆盖率、
  dist headless smoke、SIGKILL 租约恢复、依赖边界与 size-limit。
- `pnpm --filter @xm/desktop build`：renderer、main、preload 三段生产构建及产物存在性检查。
- `git diff --check` 与工作树审计：无空白错误；测试临时日志不进入交付。
