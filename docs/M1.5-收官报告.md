# M1.5 收官报告

**日期**：2026-08-12
**结论**：M1.5 已收敛为“主机范围自主 + 核心资源保护”基线，可承接 M2 的 edit/diff/search/git/checkpoint 回滚。

## 已关闭

- 数据、配置、密钥与安全源码获得不可覆盖的内建工具策略保护。
- 原始 PTY stdin 移除，改为受控 argv 运行、只读状态与持久化命令生命周期。
- `tools.disabled` 与平台可用性贯通提示词、分发和安全面板。
- checkpoint、配置/密钥文件、API Key SecretRef 持久化与 SQLite schema version 改为失败显式。
- 生产装配不再注册 `demo.*`；Electron 拒绝新窗口和外部顶层导航。
- Windows 目录链接回归使用 junction；headless 命令使用真实跨平台可执行程序。
- `pnpm verify` 新增本地供应链检查与 Kernel 85% 行覆盖率门槛。
- Turn 已拆出请求构建、工具分发、checkpoint 与结果截断；Desktop 已拆出生产工具、Provider/配置与导航安全；Gateway 已拆出路径解析，相关文件重新回到规模闸门内。

## 本地验收证据

- 2026-08-12 Windows 本地 `pnpm verify`：通过。
- 全量测试：85 个测试文件通过、1 个按既有能力条件跳过；1050 个测试通过、21 个跳过。
- Kernel 专项覆盖率：行 96.59%、分支 85.85%，高于 85% 行门槛。
- headless smoke、写租约 SIGKILL 恢复、依赖边界、单文件规模、本地供应链和 7.37 kB 体积预算：全部通过。
- 远端 Windows/Linux/macOS CI 尚未在本地任务中触发或读取；三平台验收仍以远端 CI 记录为准。

## 剩余边界

- 当前不是 OS 沙箱；任意解释器或第三方子进程可能绕过策略解析。
- 目录与超大文件的 checkpoint 仍只告警，完整目录回滚属于 M2。
- PTY 无原始交互，不承诺 REPL/全屏程序。
- 本地静态供应链检查不覆盖公开 CVE，项目不宣称已覆盖。

## M2 准入条件

1. 本地 Windows `pnpm verify` 全绿，工作树无测试污染。
2. 远端 Windows/Linux/macOS CI 全绿后才宣称三平台验收完成。
3. M2 可开放 edit/diff/search/git/checkpoint 回滚；在并行子 Agent、MCP、插件、无人值守或第三方代码执行前，必须先完成受限执行器/OS 沙箱。

最终验收证据以当次 `pnpm verify` 输出与 CI 记录为准，不以本文的静态声明代替运行证据。
